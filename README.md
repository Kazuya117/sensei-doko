# 先生いまどこ？

放課後や休み時間に、先生を探し回る時間をなくすための学内向けアプリ（PWA）です。
三田国際科学学園 リベラルアーツのテーマ「AIを活用して生産効率を上げる」の試作版です。AIは開発に使い、アプリの中では使っていません。

## しくみ

1. 生徒が、会いたい先生を選んで「さがす」を押す。
2. ほかの生徒の「こたえる」に、その先生の名前が出る。
3. 見かけた生徒が、校内マップで場所を押し、「たった今／30分くらい前／1時間くらい前」を選ぶ。
4. 探している生徒に、場所が届く。会えたら「会えた」を押す。

先生自身が「ここにいます」「会議中です」などを知らせることもできます。

## 見本モード

ログイン画面の「ログインせずに、見本を見る」（または URL の末尾に `?demo` を付ける）で、架空の先生・生徒・校舎を使ってひととおりの動きを見られます。「さがす」を押すと、数秒後に架空の生徒が「見かけた」と答えます。見本の中で押した内容はサーバーに送られず、画面を閉じると消えます。本物の先生や校内の配置は含みません（`app.js` の `DEMO_PLACES` / `demoDb`）。

## 先生を守るための決まり

居場所を扱うアプリなので、次の決まりをデータベース側で強制しています。画面側のチェックは案内のためのものです。

- 探せるのは、自分でログインして参加を選んだ先生だけ。
- 先生が「いまは探さないで」にしている間は、探すことも報告することもできない。
- 報告できるのは、だれかがその先生を探しているときだけ。
- 報告が見えるのは、探している本人・先生本人・報告者だけ。先生の居場所の一覧はない。
- 報告は2時間で見えなくなり、削除される。探した記録には場所を残さない。
- 報告者がだれかは、だれにも読めない。だれが探しているかは、本人にしか見えない。
- 選べる場所は登録済みの校内の場所だけ。保健室などは選べない。
- 使えるのは月〜土の7時〜19時。探すのは1日10回まで、同じ先生の報告は10分に1回まで。

## 構成

- 画面：ビルド不要の静的サイト（HTML・CSS・JavaScript）。GitHub Pages で配信。
- データ：Supabase（東京リージョン）。「アイデアの種」と同じプロジェクトを使い、テーブル名は `td_` で始まる。
- ログイン：Google ログイン。`@mita-is.ed.jp` のアカウントと、個別に許可したアドレスだけ。
- 校内マップ：部屋の名前と配置はデータベース（`td_places`）にあり、ログインした人にだけ届く。このリポジトリには含めていない。
- テーブル・権限・関数の定義は、Supabase のマイグレーション（`sensei_doko_tables`、`sensei_doko_rules`、`sensei_doko_deletes`）として記録している。

`app.js` に書いてある Supabase のキーは公開用（publishable）で、ページに含めてよい種類のものです。

## 運営メモ

- 先生として参加できるアドレスは、管理者が「設定」画面から登録する（`private.teacher_emails`）。同意をもらった先生だけを登録すること。
- 場所の追加・変更は `td_places` を直接編集する。`selectable = false` にすると、地図には描かれるが選べなくなる。
- 使える時間帯は `private.td_school_hours()` で変えられる。

## 更新するとき

`app.js` の `VERSION`、`index.html` の `?v=`、`sw.js` の `CACHE` と `?v=` を同じ数字に上げると、利用者の端末に新しい版が届きます。

## まだないもの

- お知らせ（プッシュ通知）。いまは20秒ごとの自動更新と、「こたえる」タブの数字で知らせている。
- 外れた報告が続く人の扱い。
- 利用データの集計画面。
