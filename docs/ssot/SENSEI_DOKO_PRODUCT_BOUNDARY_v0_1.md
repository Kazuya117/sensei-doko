# 先生いまどこ？ PRODUCT BOUNDARY v0.1 (DRAFT 2026-10-23)

## 第 1 章 作るもの（現行の機能・実装済み）

| ID | 機能 | 誰が | 画面 | 実装の所在 |
|---|---|---|---|---|
| S1-1 | 会いたい先生を選び、用件を選んで「さがす」（文字入力なし・2 タップ） | 生徒 | さがす | `td_searches` への insert |
| S1-2 | 誰かが探している先生について、校内マップで場所と「たった今 / 30 分くらい前 / 1 時間くらい前」を知らせる | 生徒 | こたえる | `td_sightings` への insert |
| S1-3 | 届いた報告を地図上の件数と時刻で見る。会えたら「会えた」で閉じる | 生徒 | さがす | `td_searches.closed_at / outcome` |
| S1-4 | 先生が「ここにいます」「会議中です（16:30 まで）」など状況を出す。「いまは探さないで」を設定する。参加をやめる | 先生 | 先生用 | `td_teachers` |
| S1-5 | 先生が、自分について知らせられた報告を見て消す | 先生 | 先生用 | `td_sightings` の delete |
| S1-6 | 先生として参加できるアドレスの登録 | 運営チーム（管理者） | 設定 | `private.teacher_emails` |
| S1-7 | 見本モード。ログインせずに架空の先生・生徒・校舎で一通りの動きを見る。数秒後に架空の生徒が答える | 誰でも | ログイン画面の「ログインせずに、見本を見る」/ `?demo` | `demoDb` / `DEMO_PLACES`（app.js 内） |
| S1-8 | ホーム画面に追加して使える（PWA）。20 秒ごとの自動更新 | 生徒・先生 | — | `manifest.webmanifest`・`sw.js` |

## 第 2 章 境界の規律

| ID | 条項 |
|---|---|
| S1-9 | **1 つの質問だけに答える。** 「いま、この先生はどこにいる可能性が高いか」以外の問いに答える機能を足さない（Charter AP-1） |
| S1-10 | **探す側と教える側は同じ生徒である。** 教える専用の役割・探す専用の役割を作らない。教える側の負担は数タップに抑える |
| S1-11 | **画面は 3 つ + 先生用 + 設定に固定する**（さがす / こたえる / 先生用 / 設定）。画面を増やす提案は本書の改版として扱う |
| S1-12 | **文字入力を増やさない。** 生徒の操作は選択だけで完結させる（急いでいる利用者が前提） |
| S1-13 | **見本モードは本番と同じ形のデータ層を使い、サーバーに一切送らない。** 本物の先生名・校内配置を見本に入れない |

## 第 3 章 作らないもの（対象外）

| ID | 作らないもの | 理由 |
|---|---|---|
| S1-14 | 先生の居場所の常時表示・一覧・履歴 | AP-4 / AP-5。監視の道具になる |

| S1-17 | AI による居場所の予測・推定 | AP-2。アプリ内で AI を使わない |
| S1-18 | 保健室・カウンセリング室・トイレ・更衣室・校外の選択 | AP-6 |
| S1-19 | 先生の行動の評価・集計の画面（個人が分かる形） | AP-1。分析は個人が分からない形に限る（SSOT-2） |
| S1-20 | 先生の了承なしに先生を探せる仕組み（運営側による代理登録を含む） | AP-3 |
